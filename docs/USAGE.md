# MyAI 使用说明

## 首次配对

1. 打开 MyAI，点「设置」。Android 的入口是右上角齿轮。
2. 填 `主机:端口`，例如 `127.0.0.1:4000` 或穿透服务的 `example.net:4000`。
3. 在服务主机上运行配对导出脚本，打开脚本同目录的 `pairing.txt`，粘贴其中的完整内容，保存并连接。等界面显示「已连接」。[配对导出命令](DEPLOYMENT.md#用平台脚本启动和导出密码)

桌面可取消勾选「在本机记住配对密码」，只在本次运行中使用它。启用记住功能时，密码存于当前系统用户的 Java Preferences。Android 在应用私有存储中保存连接信息。每台设备独立配置，已连接同一网关的客户端共享已提交的对话与附件。

## 日常聊天

- 桌面左栏可新建和搜索历史。Android 点击左上角菜单，滑出历史面板。
- 同一对话内可继续追问。每轮带最近 8 轮已完成的上下文。
- 直接输入文字并点「发送」。桌面也可按 Ctrl+Enter，Mac 使用 Command+Enter。
- 点「添加附件」或 Android 输入框旁的加号，每次可附一个不超过 5 MiB 的文件。图片上传时会压缩为 JPEG。
- 可提取有文字层的 PDF、DOCX、XLSX 和 UTF-8 文本的内容。扫描 PDF 先做 OCR。
- 想让 MyAI 生成图片或文件，先把本轮回复格式改成「生成图片」「Word」「PDF」或「Excel」。Excel 返回一张数据表。
- 点「预览图片」查看图片，点「保存附件」选择保存位置。

## 自查连接

| 提示 | 检查项 |
| --- | --- |
| 连接超时 | 核对服务是否在运行，端口和穿透映射是否正确。 |
| 配对失败 | 核对完整密码。服务换过证书或重置密码时，从主机重新读取。 |
| Codex 执行失败 | 在网关主机检查 Codex CLI 的登录、额度和网络。 |
| PDF 生成失败 | 核对网关的 TrueType 字体配置。 |

网关会把处理所需的文字和附件内容交给在线 Codex 服务。任务历史和附件副本保存在你的网关主机。
